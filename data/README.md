# Corpus documentaire

Les documents utilisés dans ce projet sont disponibles sur arXiv.

Les PDF ne sont pas redistribués dans ce dépôt afin de respecter les droits d'auteur et les licences des publications.

## Documents

1. **Attention Is All You Need**
   - Authors: Vaswani et al.
   - arXiv: https://arxiv.org/abs/1706.03762

2. **Retrieval-Augmented Generation for Knowledge-Intensive NLP Tasks**
   - Authors: Lewis et al.
   - arXiv: https://arxiv.org/abs/2005.11401

3. **Dense Passage Retrieval for Open-Domain Question Answering**
   - Authors: Karpukhin et al.
   - arXiv: https://arxiv.org/abs/2004.04906

4. **Sentence-BERT: Sentence Embeddings using Siamese BERT-Networks**
   - Authors: Reimers and Gurevych
   - arXiv: https://arxiv.org/abs/1908.10084

5. **Lost in the Middle: How Language Models Use Long Contexts**
   - Authors: Liu et al.
   - arXiv: https://arxiv.org/abs/2307.03172

## Utilisation

Les documents doivent être téléchargés depuis leurs sources officielles et placés dans le dossier `data/documents/`.

Chaque document reste soumis à sa propre licence, consultable sur sa page arXiv.
